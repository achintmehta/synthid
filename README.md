# SynthID experiments

The code and media behind my post [*Understanding SynthID: What can AI watermarks do and what they can't*](https://www.achintmehta.com/ai-arena/detecting-ai-content-synthid/), a long look at how Google's SynthID watermarks work for text, 
images, video and audio, what the other labs do, and what survives when you edit a marked file.

```
code/     three small scripts: tournament sampling on a toy vocabulary, plain vs
          watermarked text from an open-weight model with the detector's scores, and
          an invisible image watermark shown with and without. Has its own README.
media/    the files from the edit experiment in the post, one folder per system, with
          the detector's verdict on every variant as a screenshot
```

## The edit experiment

Generated one piece of media from each of three systems, all on the same prompt, sunlight
breaking through clouds. This media was modified in differetn ways and 
then run through the synth id detectors to see if the synth id detectrs can still detect
whether the media was generated by AI. 

| Folder | What it is | Mark it carries |
|---|---|---|
| `media/chatgpt/` | PNG image from ChatGPT | SynthID (OpenAI adopted Google's image watermark) |
| `media/gemini/` | JPEG image from Gemini | SynthID |
| `media/flowmusic/` | ten-second MP4 from Google Flow with its own soundtrack | SynthID in the video frames and, separately, in the audio |
| `media/claude/` | PNG image made by Claude, as a control | Content Credentials (C2PA) only, no pixel watermark |

Each original is `clouds.<ext>` and every other file is one edit of it, named by
the edit. The stills were edited in GIMP and the video in Vegas Pro:

| Suffix | Edit |
|---|---|
| `_exported` | opened and saved again with nothing changed |
| `_gaussian_blur_5`, `_10`, `_20`, `_50` | Gaussian blur, sigma in pixels. The Vegas blurs were set to the same sigma as the GIMP ones (at 1920x1080, Vegas range = sigma / 583.6, measured from a blurred test pattern) |
| `_desaturated` | colour removed |
| `_cropped_center_50`, `_cropped_top_left_50` | half the width and half the height kept, from the centre or the top-left corner |
| `_rotated_5` | rotated 5 degrees |
| `_rotated_90` | rotated 90 degrees inside the original canvas, which leaves bars at the sides and discards the top and bottom |
| `_rotated_90_uncropped` | rotated 90 degrees with the canvas enlarged so nothing is lost |

For the video, the soundtrack is muted in every edited render.

`detection_results/` in each folder holds a screenshot of the verdict for each
variant: from [synthid.com](https://synthid.com) for the ChatGPT, Gemini and Flow
files, and from [claude.com/check-content](https://claude.com/check-content) for
the Claude file.

The Content Credential on the Claude PNG was gone after a plain export with nothing changed, 
while the SynthID marks in the other three files survived the same export. 
(The Claude PNG carries no SynthID mark, which is why it serves as the control for the metadata route.) 

Blur has a threshold, around sigma 20 px for the stills and lower for video. 
A 5 degree rotation and a quarter crop passed everywhere. A 90 degree rotation inside the original canvas 
defeated the detector for all three files. The full table and the reasoning are in the post.

## Reproducing the code results

See [`code/README.md`](code/README.md). The three scripts need a Python virtual
environment and, for the text one, a 3 GB model download. None needs an API key.
